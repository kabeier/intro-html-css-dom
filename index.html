HTML, CSS & the DOM

How a web page is built before any framework: HTML for what is on the page, CSS for how it looks, and (in lecture 2) JavaScript for what it does. We build a Trainer profile page one short step at a time. Everything opens in a new tab, so keep this page open as your home base.
